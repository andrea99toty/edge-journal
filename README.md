# Edge Journal

Trading journal personale. I dati sono su un database privato e si vedono solo dopo il login.

## Versioni
Ogni aggiornamento è registrato in [CHANGELOG.md](CHANGELOG.md) e ha un'etichetta su GitHub (v1.0, v1.1, …).
Per tornare a una versione precedente basta chiedere a Claude di ripristinare l'etichetta che si vuole: il file `index.html` torna com'era in quella versione e i dati restano intatti.
