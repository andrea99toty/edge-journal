# Edge Journal

Trading journal personale. I dati sono su un database privato e si vedono solo dopo il login.

## Versioni
Ogni aggiornamento è registrato in [CHANGELOG.md](CHANGELOG.md) e lascia una copia completa nella cartella [`versioni/`](versioni/) (index-v1.0.html, index-v1.1.html, …).
Per tornare a una versione precedente basta chiedere a Claude di ripristinarla: la copia scelta torna a essere `index.html` e i dati su Supabase restano intatti.
